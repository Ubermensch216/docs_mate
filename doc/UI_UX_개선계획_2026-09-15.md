# UI/UX 개선 계획 — 최우선 작업

> 문서 상태: **구현·자동 검증 완료 / 실사용 파일럿 후속**. 계획 1~4의 구현 결과와 최신 전체 앱 화면은 [화면 캡처 안내](screenshots/README.md)에서 확인한다. 기존 603건 문서 화면은 당시 회귀 검증 기록으로 보존한다.

## 목표

후임자가 전체 자료에 접근하고, 검색 결과가 없거나 AI를 쓸 수 없는 이유를 이해하며, 다음 행동을 바로 선택할 수 있게 한다. 기존 4개 메뉴와 밝기·글자 크기 설정을 유지한다.

## 구현 순서

1. **문서 탐색 완성**: 500건 제한을 페이지 탐색으로 교체한다. 전체 검색 결과 수·표시 범위·현재 페이지를 표시하고, 검색/필터 변경 시 첫 페이지로 이동한다. 빈 자료와 검색 결과 없음을 구별하고 검색 초기화를 제공한다. 상세 패널 폭을 조절할 수 있게 한다.
2. **설정 응답성과 모델 선택**: 화면 설정을 열 때 AI 응답을 기다리지 않게 한다. AI 상태는 시스템 화면에서 비동기로 조회한다. 생성·검색 모델을 프로젝트별로 선택·저장하고 저장 결과 및 검색 준비 필요 상태를 안내한다.
3. **질문 대기 경험**: 응답 대기 중 경과 시간과 안내를 표시하고 취소를 제공한다. 취소한 답이 뒤늦게 화면을 덮지 않게 한다. 모델 예열과 종료 수명을 점검한다.
4. **시각·접근성 확인**: 밝은/어두운 테마, 기본/큰 글자, 창 크기별로 문서·설정·질문 화면을 확인한다. 키보드 탐색, 명시적 버튼 이름, 긴 파일명·빈 상태를 검증한다.

## 합격 기준

- 500건을 넘는 자료와 검색 결과의 마지막 페이지에 접근할 수 있다.
- 검색/필터/페이지 이동 후 선택된 문서와 상세 내용이 일치한다.
- 결과가 없는 이유와 검색 초기화 행동이 화면에 나온다.
- AI 서버가 느리거나 꺼져 있어도 화면 설정은 즉시 조작할 수 있다.
- 저장한 모델을 실제 분석·질문 호출이 사용하고, 없는 태그를 준비 완료로 표시하지 않는다.
- 질문 취소 후 이전 답변이 새 화면을 덮지 않으며 작업 종료가 안전하다.
- UI 회귀 테스트와 실제 위젯 렌더링으로 결과를 확인한다.

## 범위 결정

전체 시각 디자인을 교체하기보다 누락된 탐색·설정·대기 상태를 먼저 해결한다. 기능 없는 장식용 버튼은 추가하지 않는다. 클로드의 과거 성능 측정은 참고하되 이번 검증 결과와 구분한다.

## 수행 결과

1~4단계 구현과 UI·작업 수명·설정 집중 검사 95개를 완료했다. 603개 문서의 마지막 페이지, 선택 유지, 검색 초기화, 설정 비동기 확인, 질문 취소를 검증했다. 밝은/어두운 테마와 큰 글자 화면을 렌더링하고 좁은 빈 상태 영역의 줄바꿈도 수정했다.

실제 사용자 대상 사용성 평가는 후속 파일럿에서 진행한다. 변경 내역과 화면은 [보완 작업 결과 보고](보완작업_결과보고_2026-09-15.md)에 기록한다.
