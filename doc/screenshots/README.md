# 최신 화면 캡처

촬영일: **2026-09-15** · 앱 소스 기준: `336a6bd`(1차 보완 완료)

## 촬영 조건

- 현재 `MainWindow`와 각 화면·설정의 실제 PySide6 위젯을 Windows에서 렌더링하고 `QWidget.grab()`으로 캡처했다. 화면을 재구성한 시안이나 AI 생성 이미지가 아니다.
- 실제 사용자 프로젝트 대신 `app.tools.make_fixtures`로 만든 합성 표본을 별도 임시 프로젝트에 넣고 현재 분석 파이프라인을 실행했다.
- 결과: 문서 77개, 완전 중복 추가본 7개, 업무 6개, 질문용 조각 138개. 업무명·설명은 해당 로컬 모델 실행 결과이며 실행마다 달라질 수 있다.
- 기본 글자 크기, 밝은 테마와 어두운 테마, 주 화면 1440×1080, 설정 940×880으로 촬영했다. 한글과 기호는 Windows 맑은 고딕·Segoe UI 계열 글꼴을 사용했다.
- 질문은 실제 설치된 `gemma4:e2b`와 `bge-m3`로 실행했다. 대기·결과·답변 유보는 실제 앱 상태다. 성공한 응답의 모양을 만들기 위해 결과를 주입하지 않았다. 이번 촬영의 `ask.png`는 `2023년 예산 요구액이 얼마야?`에 대한 유보 화면이며, 기존 평가셋의 기대와 다른 관찰은 [후속 점검](../01_현재구현_및_검증현황.md#6-문서-현행화-중-추가-관찰)에 기록했다.
- 합성 자료의 로컬 경로가 일부 화면에 보인다. 실제 기관 자료·개인정보·사용자의 업무 프로젝트는 촬영하지 않았다.

## 갱신 기준

1. 현재 소스와 검증용 합성 자료로 별도 프로젝트를 만든다. 개인 프로젝트를 사용하지 않는다.
2. 자료 분석 완료와 모델 상태를 확인하고, 정상 탐색·대기·유보를 포함한 실제 동작을 촬영한다.
3. 원본 이미지에서 글자·아이콘·선택 문서·페이지·근거 표시가 일치하는지 확인한다.
4. 화면을 변경하면 루트 README 이미지, 이 목록, 캡처 날짜와 소스 기준을 함께 갱신한다.

`doc/review_2026-09-15/`의 603건 문서 화면은 앞선 UI 회귀 검증 기록이다. 최신 제품 소개 화면은 이 폴더를 사용한다. 캡처만으로 실제 사용자 사용성·기관 자료 품질·저사양 성능을 통과했다고 표시하지 않는다.
