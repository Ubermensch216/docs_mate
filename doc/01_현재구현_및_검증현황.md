# 현재 구현 및 검증 현황

기준일: 2026-09-15 · 구현 기준 커밋: `336a6bd`(1차 보완 완료)

이번 후속 작업은 프로젝트 문서와 화면 캡처를 현행화한다. 아래 수치는 앞선 코드 보완의 실제 실행 기록이며, 문서 수정만으로 새 전체 테스트 결과를 만든 것으로 표시하지 않는다.

## 2. 문서 형식과 한계

| 형식 | 현재 범위 |
|---|---|
| DOCX·PPTX·XLSX/XLSM | 본문·슬라이드·시트 추출. 형식별 원문 위치 연결 |
| PDF | 텍스트 레이어 추출. 스캔 이미지 OCR 제외 |
| HWPX | XML 본문 추출. 합성 표본 1건 자체 점검 통과 |
| HWP | HWP 5.0 본문 파서 구현. 표 구조 보존 제한, 실제 HWP 회귀 표본 미확보 |
| TXT·CSV·MD·LOG | 텍스트 추출 |
| DOC·XLS·PPT, HWP 3.0 | 미지원 상태 안내 |
| 이미지·이메일 | OCR·메일 본문/첨부 추출은 후속 |

파서 구현 여부와 실제 기관 문서의 파싱 품질을 구분한다. 실패·부분 추출·잠김·크기 초과는 문서 상태로 확인한다.

## 3. 검증 근거

| 검사 | 기록 |
|---|---|
| 전체 회귀 | **902 통과, 4 건너뜀, 경고 1**, 295.81초 |
| UI·작업 수명·설정 집중 검사 | 95 통과. 전체 검사와 중복되는 항목이며 합산하지 않음 |
| 실제 AI를 포함한 별도 검사 | **36 통과**, 42.52초. 이 중 실제 모델을 호출하는 테스트는 3개 |
| 최종 실행 파일 자체 점검 | 합성 문서 **77개 정상 추출**, 필수 로고·SQL·프롬프트 확인 |
| 최신 소개 화면 | 현재 Qt 위젯을 합성 자료로 렌더링. 실제 사용자 사용성 평가는 아님 |

전체 검사의 건너뜀 4건은 실제 AI 선택 검사 3건과 외부 실문서 검사 1건이다. 실제 AI 3건은 별도 검사에서 통과했다. 경고 1건은 기존 테스트의 오래된 Qt 마우스 이벤트 호출이다. 커버리지 수치는 이번 실행에서 산출하지 않았다.

실행 환경: Windows, Python 3.14.6 및 `requirements.lock`. [실행 기록과 결과 보고](보완작업_결과보고_2026-09-15.md)를 참조한다. 이전 RAG 계획의 9문항 정확도·응답 지연은 당시 실험값이며 이번 일반 회귀 테스트 수치와 다른 지표다.

## 4. 실행·갱신·운영

- 사용자 실행과 개발 명령은 [프로젝트 README](../README.md)를 따른다.
- 검증용 배포본은 `dist/review-20260915-final/NunchiCoach/`이다. 저장소에서 생성한 로컬 산출물이며 Git에서 내려받으면 자동으로 존재하는 파일이 아니다.
- 배포 폴더 전체를 유지한다. 실행 파일만 복사하면 안 된다. Ollama와 모델은 별도로 준비한다.
- 기존 프로젝트 첫 실행이나 검색 모델 변경 시 재분석 시간을 확보한다.
- 진단 로그는 프로젝트의 `logs/diagnostic.log`와 회전 파일에 기록된다. 본문·질문·원본 경로·예외 메시지를 넣지 않는다. 감사 로그와 DB에는 업무 정보가 있으므로 접근 권한을 별도로 관리한다.
- 실행 의존성과 개발·빌드 의존성은 현재 같은 잠금 파일에 들어 있다. 분리는 후속 유지보수 항목이다.

## 5. 완료로 표시하지 않는 항목

실제 기관 자료·100문항 이상 평가셋, 8GB PC 성능, 실제 HWP, 서명·기관 반입, Python 없는 오프라인 PC, 백업·복원 운영 절차, 공개 라이선스, 원격 CI 실행은 [파일럿 계획](파일럿_및_배포_검증계획.md)의 후속 항목이다. 조직 공유·권한 관리·그래프 화면·복사본 자동 정리는 현재 MVP 범위 밖이다.

## 6. 문서 현행화 중 추가 관찰

최신 화면 촬영용 새 합성 프로젝트(77문서·138조각, 기본 모델)에서 다음 두 질문이 답변 유보로 끝났다. 두 질문은 기존 `tests/fixtures/rag_eval/cases.json`에서 답변 대상으로 정의된 `year-scope`, `table-needs-context`에 해당한다.

- `2025년 행정사무감사 때 뭘 제출했어?`
- `2023년 예산 요구액이 얼마야?`

이는 촬영 중 관찰한 개별 사례이며 정식 9문항 반복 평가를 수행한 결과는 아니다. 원인은 아직 분리하지 않았다. 검색 후보·범위 적용, 생성 결과, 숫자·문장 검증에서 유보된 이유를 재현 프로젝트로 확인해야 한다. 일반 회귀 902개와 실제 AI 포함 36개의 과거 통과를 모든 합성 질문의 현재 품질 보장으로 해석하지 않는다.

[현재 질문 결과 화면](screenshots/ask.png)은 이 실제 유보 상태다. 이미지에 성공 답변을 주입하지 않았다. 이 관찰을 [RAG 계획](질문화면_RAG_개선계획.md)과 파일럿 전 점검 항목에 반영했다.
